GUIDE

Getting Started

1. Allow permissions

Follow the app’s permission prompts. Allow location access for speed and route tracking, and Bluetooth access for camera discovery. If access was denied, review mOmentiOn’s permissions in system Settings.

Android: the setup includes location and nearby-device permissions, overlay access for the floating button, and an optional storage folder choice. Follow the prompts for your Android version; overlay access is needed only to show the button over other apps.

iOS: allow location access when requested; the app initially asks for access while in use. Route files are stored inside the app, so there is no Android-style storage folder selection. The app-switch button opens a selected map app rather than a floating overlay.

2. Check GPS reception

While stationary with a clear view of the sky, make sure GPS monitoring is on using the top-right GPS button. Check the GPS indicator and live log for a received location. A speed value of zero alone does not confirm GPS reception.

3. Connect your camera

Turn the camera on and select its brand in Settings. Insta360 uses camera Wi-Fi with Bluetooth setup; DJI uses Bluetooth control. Tap Connect and approve prompts on the phone or camera. Wait for the main button to turn green and for the connection log before testing recording.

4. Test manual recording

While stationary, tap the main button and follow any countdown or usage prompt. Confirm the red REC state and that the camera is recording. Tap again to stop and check that the camera saves the clip. If X is shown, stop the recording on the camera itself.

5. Set automatic recording

In Settings, choose start and stop speeds and their hold times. Keep the stop speed below the start speed. Automatic recording needs GPS monitoring and a ready camera connection; it starts or stops when the configured speed conditions persist for the hold time. Manual recording is not stopped by the automatic stop speed.

6. Finish and review

After riding, stop safely before using the phone. Replay, compare or share from Saved rides, and check Saved logs if something went wrong. Use the red Quit button to finish monitoring and camera connections. Recording started on the camera itself must be stopped on the camera.

8. Before You Ride

Configure and test while stationary. Do not operate your phone while riding. GPS reception and camera connection affect automatic recording.
