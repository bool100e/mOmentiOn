Getting Started

1. Allow permissions

Allow location and Bluetooth. The floating button requires display-over-other-apps permission (Android).

Details

Allow location and Bluetooth access. Change denied permissions in system Settings.

Android: the setup includes location and nearby-device permissions, overlay access for the floating button, and an optional storage folder choice. Follow the prompts for your Android version; overlay access is needed only to show the button over other apps.

iOS: allow location access when requested; the app initially asks for access while in use. Route files are stored inside the app, so there is no Android-style storage folder selection. The app-switch button opens a selected map app rather than a floating overlay.

2. Check GPS reception

While stationary, enable GPS monitoring and check reception. Zero speed alone does not confirm reception.

Details

Stop with a clear view of the sky, enable GPS monitoring, and check reception in the indicator and log. Zero speed alone does not confirm reception.

3. Connect your camera

Turn on the camera → select brand → connect → approve pairing. A green main button confirms connection.

Details

Turn on the camera, select its brand, and connect. Approve pairing and wait for the green main button.

4. Test manual recording

Use the main button to start and stop. If X appears, stop recording on the camera.

Details

While stationary, tap the main button and follow any countdown or usage prompt. Confirm the red REC state and that the camera is recording. Tap again to stop and check that the camera saves the clip. If X is shown, stop the recording on the camera itself.

5. Set automatic recording

Set start/stop speeds and hold times. Keep the stop speed lower; manual recording does not stop automatically.

Details

Set start/stop speeds and hold times. Keep the stop speed lower. With GPS and camera ready, recording follows these conditions. Manual recording does not stop automatically.

6. Finish and review

Stop safely, review your records, and tap Quit. Stop camera-started recording on the camera.

Details

After riding, stop safely before using the phone. Replay, compare or share from Saved rides, and check Saved logs if something went wrong. Use the red Quit button to finish monitoring and camera connections. Recording started on the camera itself must be stopped on the camera.

7. Camera Compatibility

Supported cameras use Bluetooth control. Find your model below.

Insta360

  • ONE X2
  • X3
  • X4
  • X4 Air
  • X5
  • X6

DJI

  • Osmo 360
  • Osmo Action 4
  • Osmo Action 5 Pro
  • Osmo Action 6
Details

On Android and iOS, mOmentiOn controls every supported camera over Bluetooth: connection, status, clock and recording. Insta360 cameras use the Insta360 SDK and DJI cameras use the DJI R SDK protocol. Behaviour may vary with camera firmware.

Android build 34 and iOS build 40 recognize ONE X2, X3, X4, X4 Air, X5 and X6 Bluetooth names. X6 support uses SDK 2.1.5 on Android and 1.11.3 on iOS. Saved-camera matching remains strict.

8. Before You Ride

Set up and test while stationary. Do not operate the phone while riding.

Details

Set up and test while stationary. Do not use the phone while riding. Automatic recording requires GPS reception and a camera connection.
