GUIDE

使い方

1. 権限を設定

位置情報・Bluetoothを許可してください。フローティングボタンには「他のアプリの上に表示」の権限が必要です（Android）。

詳しく

位置情報・Bluetoothを許可してください。拒否した権限はシステム設定で変更できます。

Android：位置情報・周辺機器・フローティング表示の権限と、任意の保存フォルダー案内があります。OSに合わせた案内に従います。重ねて表示する権限はフローティングボタンに必要です。

iOS：要求時に使用中の位置情報アクセスを許可します。経路はアプリ内に保存され、Androidのようなフォルダー選択はありません。アプリ移動ボタンは重ねて表示せず指定地図アプリを開きます。

2. GPS受信を確認

停車中にGPS監視を有効にし、受信を確認してください。速度0だけでは受信を判断できません。

詳しく

空の見える場所に停車し、GPS監視を有効にして表示・ログで受信を確認してください。速度0だけでは受信を確認できません。

3. カメラを接続

カメラをオン → ブランド選択 → 接続 → ペアリング許可。メインボタンが緑なら接続完了です。

Insta360：Bluetooth Wakeupをオン
接続する前に、カメラの設定でBluetooth Wakeupをオンにしてください。

初回接続には少し時間がかかる場合があります。メインボタンが緑色になるまでお待ちください。

詳しく

カメラの電源を入れ、ブランドを選んで接続してください。ペアリングを許可し、メインボタンが緑になるまで待ちます。

カメラ画面を上から下にスワイプし、お使いのモデルのメニューを開いてください。

  • X5 / X4 Air：設定 → 一般 → Bluetooth Wakeup → オン。
  • X3 / X4 / X6：設定 → Bluetooth Wakeup → オン。
  • ONE X2：設定 → 一般 → Bluetooth Wakeup → オン。

Bluetooth Wakeup公式ガイド

4. 手動録画をテスト

メインボタンで開始・停止します。Xが表示されたらカメラ本体で停止してください。

詳しく

停車中にメインボタンを押し、カウントダウンや利用案内に従います。赤いRECと実際の録画を確認し、再度押して停止・保存を確認します。Xが表示される場合はカメラ本体で停止します。

5. 自動録画を設定

開始・停止速度と継続時間を設定してください。停止速度は低く設定し、手動録画は自動停止しません。

詳しく

開始・停止速度と継続時間を設定してください。停止速度は低く設定します。GPS・カメラの準備後、条件に従って自動録画します。手動録画は自動停止しません。

6. 終了して記録を確認

停車後に記録を確認して終了ボタンを押してください。本体で始めた録画は本体で停止します。

詳しく

走行後は安全に停車してから操作します。保存経路で再生・比較・共有し、問題があればログを確認します。終了は赤いボタンで監視と接続を終了します。本体で開始した録画は本体で止めてください。

7. カメラ互換性

対応カメラはBluetoothで制御します。機種は下の一覧で確認してください。

Insta360

  • ONE X2
  • X3
  • X4
  • X4 Air
  • X5
  • X6

DJI

  • Osmo 360
  • Osmo Action 4
  • Osmo Action 5 Pro
  • Osmo Action 6
詳しく

mOmentiOnはAndroid・iOSともに、対応カメラをBluetoothで制御します。接続、状態確認、時刻設定、録画をすべてBluetoothで行います。Insta360はInsta360 SDK、DJIはDJI R SDKプロトコルを使用します。カメラのファームウェアによって動作が異なる場合があります。

Android ビルド34とiOS ビルド40はONE X2・X3・X4・X4 Air・X5・X6のBluetooth名を認識します。X6対応にはAndroid SDK 2.1.5とiOS SDK 1.11.3を使用します。保存済みカメラを厳密に識別します。

8. 走行前の確認

停車中に設定・テストし、走行中はスマートフォンを操作しないでください。

詳しく

停車中に設定・テストしてください。走行中はスマートフォンを操作しないでください。自動録画にはGPS受信とカメラ接続が必要です。
