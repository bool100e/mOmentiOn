iOS 36 · Android 27 — Stationary detection

2026-10-03

PlatformApp versionBuildDistribution at the time
iOS1.036Internal TestFlight testing
Android1.027Google Play closed Alpha testing

Test release: iOS build 36 is available to the existing internal TestFlight group. Android version code 27 is available to Google Play closed Alpha testers.

Stationary speed and automatic recording stop

Common changes

  • When the stop speed is set to 0, valid GPS speeds at or below 0.9999 km/h now satisfy the automatic stop condition. The configured stop delay still applies.
  • Valid speeds from 0 to 0.9999 km/h are displayed as 0 to reduce stationary GPS jitter.
  • For a stop speed of 0, stationary readings clear residual speed smoothing. Speeds above 0.9999 km/h interrupt the stop delay.
  • Missing, invalid, stale, or inaccurate GPS speed readings are excluded from automatic stop decisions; loss of GPS is not treated as a stationary reading.
  • Nonzero stop-speed settings and manual recording behavior are unchanged.

iOS development notes · Build unverified — Connection and recovery

2026-10-01

PlatformApp versionBuildDistribution at the time
iOSNeeds verificationNeeds verificationLocal development notes; not in build 27 at the time

Historical development notes from October 1. The platform table describes the status at that time, not current availability.

Camera connection and recording recovery

iOS changes

  • Initial camera connection: if no camera has connected successfully before, the Connect button alternates between Insta360 and DJI after a failed attempt.
  • Brand cycling ends when a connection succeeds, you cancel, or a permission or approval error requires your action. Reconnection after a previous successful connection keeps the selected brand.
  • Recording recovery: after a communication error, the app reconnects if a status check confirms that recording did not start or has not stopped.
  • Recovery checks the actual camera state. A manual start is not automatically repeated; a pending stop follows the existing speed and recording-source rules.
  • Connection button icons now match Android: cancel while connecting or waiting to retry, reconnect when connected, and retry after a failed connection. The yellow pulse continues during retry delays.

iOS 21 · Android 22 — Route replay and sharing

2026-09-28

Test build notes · Google Play closed testing / TestFlight. Availability may depend on review and rollout status.

The route page now brings map replay and graphs together vertically. Summary images and videos follow the same composition. This build also introduces the iOS app.

Highlights

Common changes

  • Unified route page: replay stays synchronized while scrolling between the map and graphs.
  • Portrait heatmap-and-graph videos: choose full length, 60, 45, 30, 15, or 5 seconds. A different playback speed is suggested for videos over 3 minutes.
  • Route and comparison summary images follow the app layout.

iOS changes

  • iOS support for speed-triggered recording, route tracking, replay, comparison, and sharing.

New Features & Improvements

Common changes

  • A compass follows map rotation in every video; logo placement and size match across platforms.
  • Video export shows remaining time, asks before cancellation, and allows only one export at a time.
  • Added a route-list lock toggle and refreshed screen tours without overlapping camera-error guidance.
  • Cause-specific camera errors link directly to connection settings.

iOS changes

  • Start, stop, and warning haptics; open GPX files from other apps on iOS.

Bug Fixes

Common changes

  • Exported video duration now matches the selected playback time.
  • Restored missing roads and rivers in summaries, fixed blank comparison images, and removed empty space above videos.

iOS changes

  • Fixed the iOS share sheet and KakaoTalk sharing.

Android changes

  • Closing an export cancels it correctly; removed duplicate speed-change prompts on Android.

Removed

Common changes

  • Landscape-only expanded graph and landscape video layouts.
  • The combined Image + GPX sharing option.
