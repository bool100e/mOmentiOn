시작하기

1. 권한과 저장 위치

권한 설정 안내를 따르고 저장 폴더 선택 항목이 제공되면 보관 위치를 지정하세요.

2. 카메라 연결

설정에서 카메라 브랜드와 연결 정보를 확인하세요. Bluetooth와 Wi-Fi를 켜고 인디케이터로 연결 상태를 확인하세요.

3. 녹화 기준 설정

시작·정지 속도와 유지 시간을 설정하세요. 출발 전 정차 상태에서 GPS 수신과 수동 녹화를 확인하세요.

4. 경로 확인

주행 후 경로 목록에서 재생·비교·내보내기를 사용하세요. 연결 문제가 있으면 로그 목록을 확인하세요.

카메라 호환성

Insta360와 DJI 연결 설정을 제공합니다. 지원 동작은 모델·펌웨어·플랫폼에 따라 다르므로 주행 전에 사용 기기에서 확인하세요.

주행 전 확인

정차 상태에서 앱을 설정하고 테스트하세요. 주행 중 휴대폰을 조작하지 마세요. GPS 수신과 카메라 연결은 자동 녹화에 영향을 줍니다.
