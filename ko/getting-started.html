GUIDE

시작하기

1. 권한 설정

위치·Bluetooth 권한을 허용하세요. 거부한 권한은 시스템 설정에서 변경할 수 있습니다.

Android: 위치·주변 기기 권한, 플로팅 버튼용 다른 앱 위 표시 권한, 선택 사항인 저장 폴더 안내가 제공됩니다. 기기 버전에 맞는 안내를 따르세요. 다른 앱 위 표시 권한은 플로팅 버튼을 표시할 때 필요합니다.

iOS: 위치 요청이 나오면 사용 중 접근을 허용하세요. 경로 파일은 앱 내부에 저장하므로 Android처럼 저장 폴더를 선택하지 않습니다. 다른 앱으로 이동 버튼은 플로팅 오버레이 대신 지정한 지도 앱을 엽니다.

2. GPS 수신 확인

하늘이 잘 보이는 곳에 정차 후 GPS 감시를 켜고 인디케이터·로그로 수신을 확인하세요. 속도 0만으로 수신 여부를 판단하지 마세요.

3. 카메라 연결

카메라를 켜고 브랜드를 선택한 뒤 연결하세요. 페어링을 승인하고 초록색 메인 버튼을 확인하세요.

4. 수동 녹화 테스트

정차 상태에서 메인 버튼을 누르고 카운트다운·이용 안내가 있으면 따르세요. 빨간 REC 표시와 카메라의 실제 녹화를 확인하세요. 다시 눌러 정지하고 카메라에 영상이 저장되는지 확인하세요. X가 표시되면 카메라 본체에서 정지하세요.

5. 자동 녹화 설정

시작·정지 속도와 유지 시간을 설정하세요. 정지 속도는 시작 속도보다 낮아야 합니다. GPS·카메라가 준비되면 속도·유지 시간 조건에 따라 자동 녹화합니다. 수동 녹화는 자동 정지하지 않습니다.

6. 종료와 기록 확인

주행 후 안전하게 정차한 뒤 휴대폰을 조작하세요. 경로 목록에서 재생·비교·공유하고, 문제가 있었다면 로그 목록을 확인하세요. 사용을 마칠 때는 빨간 종료 버튼으로 감시·연결을 종료하세요. 본체에서 시작한 녹화는 카메라에서 직접 정지해야 합니다.

7. 카메라 호환성

mOmentiOn은 Android·iOS 모두 지원 카메라를 Bluetooth로 제어합니다. 연결, 상태 확인, 시간 설정, 녹화를 모두 Bluetooth로 처리합니다. Insta360은 Insta360 SDK, DJI는 DJI R SDK 프로토콜을 사용합니다. 카메라 펌웨어에 따라 동작이 다를 수 있습니다.

8. 주행 전 확인

정차 후 설정·시험하세요. 주행 중 휴대폰을 조작하지 마세요. 자동 녹화에는 GPS 수신과 카메라 연결이 필요합니다.
